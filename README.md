# PropostaA3
Plano de Objetivo do Projeto – A3
Nome do projeto: Quebra-cabeça dos Animais
Área: Análise e Desenvolvimento de Sistemas
Tipo de projeto: Desenvolvimento de uma aplicação web utilizando HTML, CSS e JavaScript.
1. Objetivo geral
Desenvolver uma página web interativa utilizando HTML, CSS e JavaScript, que apresente um jogo de quebra-cabeça com imagens de animais. O objetivo é proporcionar entretenimento e aprendizado, estimulando o raciocínio lógico, a concentração e a capacidade de reconhecimento dos animais por meio de desafios interativos.
2. Objetivos específicos
Desenvolver uma interface simples, intuitiva e de fácil utilização.
Implementar quebra-cabeças utilizando imagens de diferentes animais.
Dividir as imagens em várias peças que deverão ser organizadas pelo jogador.
Criar uma limitação de movimentação, permitindo mover apenas peças próximas ou adjacentes ao espaço vazio.
Adicionar animações durante a movimentação das peças, tornando a experiência mais dinâmica.
Após completar o quebra-cabeça, apresentar opções de palavras para que o jogador identifique corretamente o animal representado.
Exibir uma mensagem de acerto ou erro após a escolha do jogador.
Permitir iniciar uma nova rodada com uma imagem de outro animal.
3. Funcionalidades principais
Funcionalidade
Descrição
Tela inicial
Apresentar o nome do jogo e um botão para começar.
Quebra-cabeça
Exibir uma imagem de animal dividida em peças embaralhadas.
Movimentação
Permitir movimentar somente peças adjacentes ao espaço vazio.
Animações
Adicionar efeitos visuais durante a movimentação das peças.
Identificação
Apresentar alternativas com nomes de animais após a montagem.
Resultado
Informar se o jogador identificou corretamente o animal.
Próxima fase
Disponibilizar outro animal para continuar jogando.

4. Tecnologias utilizadas
HTML5: responsável pela estrutura e organização dos elementos da página.
CSS3: utilizado para desenvolver o visual do jogo, cores, posicionamento das peças e animações.
JavaScript: responsável pela lógica do quebra-cabeça, movimentação das peças, validação das respostas e funcionamento das fases.
5. Metodologia de desenvolvimento
O projeto será desenvolvido em etapas:
Planejamento: definir o funcionamento do jogo, as regras e a aparência da interface.
Estruturação: criar a página HTML e organizar os elementos necessários.
Estilização: desenvolver o design utilizando CSS, incluindo as animações de movimentação.
Programação: implementar a lógica de embaralhamento, movimentação das peças e identificação dos animais.
Testes: verificar se as peças respeitam as limitações de movimentação e se o jogo funciona corretamente.
Finalização: realizar correções e melhorias na interface e na experiência do jogador.
6. Resultados esperados
Espera-se desenvolver um jogo funcional e interativo, que combine diversão e aprendizado. O jogador deverá conseguir montar imagens de diferentes animais, respeitando as regras de movimentação das peças, e posteriormente identificar corretamente o animal apresentado.
Além disso, espera-se que as animações e a interface tornem o jogo mais agradável, proporcionando uma experiência simples e dinâmica.
7. Justificativa do projeto
A escolha desse projeto surgiu da ideia de desenvolver uma aplicação que una entretenimento e aprendizado. O jogo de quebra-cabeça permite trabalhar conceitos de lógica de programação, manipulação de elementos HTML, estilização CSS e eventos JavaScript.
Também possibilita desenvolver habilidades de resolução de problemas, organização e planejamento, aplicando na prática os conhecimentos adquiridos durante o curso de Análise e Desenvolvimento de Sistemas.
8. Diferencial do projeto
O principal diferencial será a combinação de um quebra-cabeça deslizante com um desafio de reconhecimento de animais. Diferentemente de um quebra-cabeça tradicional, o jogador não precisará apenas montar a imagem, mas também demonstrar que reconhece o animal apresentado.
A movimentação limitada das peças e as animações também tornam o desafio mais interessante, exigindo atenção e raciocínio lógico.
Nome sugerido para o jogo: Quebra-cabeça dos Animais.
